تعليمات نشر تطبيق Points

1) ارفع جميع محتويات هذا المجلد إلى جذر مستودع GitHub الخاص بهذا التطبيق.
2) يجب أن يكون ملف index.html في جذر النشر، وبجواره manifest.webmanifest و sw.js ومجلد icons.
3) فعّل GitHub Pages من Settings > Pages واختر الفرع/المجلد الذي يحتوي index.html.
4) افتح رابط GitHub Pages عبر HTTPS.
5) على Android: افتح الرابط في Chrome ثم اختر تثبيت التطبيق أو إضافة إلى الشاشة الرئيسية.
6) على iPhone: افتح الرابط في Safari ثم مشاركة > Add to Home Screen.

ملاحظة: الاتصال بالإنترنت مطلوب لوظائف Firebase والبيانات الحية. Service Worker يحفظ هيكل الصفحة فقط ولا يخزن بيانات الطلاب أو الحسابات.
